# История технического аудита

Актуальный статус 1.0.3-alpha.1: [docs/VALIDATION.md](docs/VALIDATION.md). Godot 4.7.2 установлен, чистый импорт и регрессии действительно выполняются. Ниже сохранены исторические заметки версии 1.0.2; старые утверждения об отсутствии движка больше не описывают текущую среду.

## Выполнено
- Исправлен путь к шейдеру фона меню: `res://Shaders/fog_menu.gdshader`.
- Уточнён комментарий версии `PreMatchUI.gd`, чтобы он соответствовал версии проекта 1.0.2.
- Результат внесён в `CHANGELOG.md` без изменения номера версии проекта.

## Проверено по исходникам
- Стартовая сцена проекта: `scenes/AuthGate.tscn`; главное меню после успешного входа: `scenes/MainMenu.tscn`.
- Игровая сцена: `scenes/Main.tscn`.
- Основные UI-модули: `scripts/MainMenu.gd`, `scripts/HUD.gd`, `scripts/PreMatchUI.gd`.
- Система тумана войны: `scripts/FogManager.gd`.
- Загрузка матча: `scripts/LoadingScreen.gd`.

## Необходимое внимание
- `res://assets/ui_click.ogg` отсутствует: звук клика не будет воспроизводиться, но меню продолжает работать.
- `res://assets/ui/loading_match.png` отсутствует: экран загрузки использует встроенный градиентный фон.
- ZIP не содержит кэш `.godot`; при первом открытии Godot создаст его заново. Сцены, скрипты и игровые ресурсы проекта включены.

## Ограничение проверки
В среде подготовки не установлен исполняемый файл Godot, поэтому запуск проекта и проверка ошибок парсинга непосредственно движком не выполнялись. Изменения проверены статически; перед релизом рекомендуется открыть проект в Godot 4.7 (версия указана в `project.godot`) и запустить главную сцену.


## Дополнительное исправление видимости персонажей
- Исправлена непрозрачность полноэкранного слоя тумана: шейдер сохраняет `COLOR.a`, а `MainMenu.gd` задаёт прозрачность слоя 0.32. Подробности: `CHARACTER_VISIBILITY_FIX.md`.


## Дополнительный патч 1.0.2 — 6 ноября 2026
- Добавлена отдельная стартовая сцена авторизации `scenes/AuthGate.tscn` и назначена главной сценой проекта.
- Служебная учётная запись больше не создаётся; старый встроенный доступ отключается миграцией.
- Админ-панель и система привилегий удалены из текущей версии.
- Исправлена передача выбранной цели в AI-подбор способностей; `Execute` фильтрует уязвимые цели до выбора, вместо отказа из-за неподходящей ближайшей цели.
- Боты дополнительно оценивают количество героев противника и союзников в радиусе боя.
- Проверка движком Godot в этой среде по-прежнему недоступна: Godot CLI не установлен. Перед публикацией следует открыть проект в Godot 4.x и проверить стартовую авторизацию, меню, выход из аккаунта и матчи 1x1/2x2/5x5.

- Тест героя остаётся обычной песочницей. Инструменты изменения матча доступны только в тестовом режиме.

- Бот теперь сохраняет выбранную цель для прицельных способностей, если она остаётся живой и находится в радиусе; ультимейт с добиванием выбирает героя с низким здоровьем.
