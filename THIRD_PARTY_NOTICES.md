# Компоненты и происхождение материалов

| Материал | Происхождение | Условия / статус |
|---|---|---|
| Godot Engine 4.7.2 | https://godotengine.org/ | MIT и лицензии включённых компонентов. https://godotengine.org/license/ |
| Файлы GDScript, сцены и шейдеры | Код проекта и изменения, подготовленные для владельца с помощью Codex | Права сохраняются, открытая лицензия не выдана |
| assets/renewal/*.svg | Оригинальная векторная графика, созданная кодом в ходе разработки | Права сохраняются |
| icon.svg | Исходная стилизованная корона проекта | Права сохраняются |
| Геометрия персонажей, карта, иконки и синтезируемые эффекты | Процедурное построение кодом проекта | Права сохраняются |
| Стандартные шрифты/элементы Godot | Поставляются движком | Лицензии Godot и его компонентов |

Неиспользуемые PNG из прежнего assets/textures исключены из публикуемого состава: происхождение не подтверждено. Оригиналы сохранены владельцу вне репозитория. В игру не включены модели, логотипы или звуки Dota 2.

В Windows-пакет включаются тексты лицензий движка и компонентов. Полный экран лицензий движка доступен в редакторе Godot; автоматический сбор лицензий пакета выполняет tools/build_windows.py.
